# Трезвый вечер

Android-приложение для изменения привычки вечернего употребления. С 1.2 это одна механика — **«Равновесие»**: у дня шесть сторон (Тело, Руки, Голова, Люди, Мир, Тишина), приложение знает, где ты (диван, комната, кухня, ванная, окно/балкон, подъезд/двор, дорога, работа, город), и предлагает один небольшой ход, который восполняет то, чего сегодня не хватило. Тяга, чекпоинты, план на вечер, голосовые заметки и ходы лежат на одной «линии дня». Без ИИ и без сети.

Не лечение и не инструмент самостоятельной отмены алкоголя. 18+.

Данные хранятся только на телефоне (`files/data.json` во внутреннем хранилище). Выгрузка: `journal.md`, `data.json`, `scenarios.json`, `audio/`.

## Устройство

| Путь | Что это |
|---|---|
| `app/src/main/assets/index.html` | Разметка и стили (WebView), переходы, `prefers-reduced-motion` |
| `app/src/main/assets/app.js` | Интерфейс: колесо дня, линия дня, карточка хода, шторки (чекпоинты, голос, тяга), Дневник, Баланс, Настройки, самотест |
| `app/src/main/assets/engine.js` | Движок без UI: модель данных (schema 3), миграция, равновесие по сторонам, подбор `balance-v1`, валидатор и проверка покрытия пакета. Работает в WebView и Node |
| `app/src/main/assets/content/core-ru.json` | Пакет контента 2.0: таксономия, 155 ходов по местам и сторонам. **Генерируется** из `tools/build-pack.mjs` |
| `app/src/main/java/.../Proactive.java` | Одноразовые напоминания, дневной лимит, тихие часы, восстановление после перезагрузки |
| `tools/` | Генератор и валидатор пакета, тесты движка |

### Как добавить или изменить сценарий

1. Править `tools/build-pack.mjs` (до появления бэк-офиса это и есть редактор). При изменении текста или условий — увеличить `revision` сценария; `id` не менять.
2. `node tools/build-pack.mjs && node tools/validate-pack.cjs && node --test tools/`
3. Валидатор проверяет таксономию (стороны, места, теги, требования), `to`/`then`, fallback у ходов вне дома, запреты (улица и нагрузка после употребления, формулировки в режиме «всё равно выпью») и покрытие: в каждом месте при обычном вечере, сильной тяге и низких силах должно найтись не меньше 4 ходов.

### Подбор `balance-v1`

Фильтр: место, режим (сейчас / на вечер / «всё равно выпью»), можно ли выйти, часы работы, сильная тяга (≤20 мин, лёгкие), уже выпил (только безопасное дома), анкета (бюджет, «не люблю», ограничения, близкие, дети, балкон), скрытые и дважды «не нравится». Балл: дефицит стороны за сегодня, «чего хочется» из отметки тяги, цепочки `then`, переход в другое место после 40 минут на одном, история «стало лучше / хуже», нагрузка дня, новизна; колода чередует стороны, 15% — исследование.

### Данные (schema_version 3)

Все новые записи: UUID, `created_at`, `updated_at`, `deleted_at`, `sync_state`, `local_date`, `tz_offset_min` — для будущей синхронизации с сервером. Коллекции: `profile`, `proactive`, `sessions`, `offers` (с `scenario_revision`, `ranker_id`, `score`, `features` — датасет для будущего ML), `responses`, `feedback` (null = «не ответил»), `prompts`, `prefs`, `events` (append-only журнал), `places_log` (смены места), `now` (текущее место, режим, «уже выпил» за сегодня). Старые записи дневника мигрируют без смены id.

## Сборка

`./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`. CI: проверка пакета и тесты движка → сборка → самотест на эмуляторе Android 14.

## Подпись

Ключ подписи в репозиторий не входит. Без ключа release-сборка подписывается debug-ключом — такой APK **не встанет поверх** версии, подписанной твоим ключом.

```bash
export TREZVO_KEYSTORE=/path/to/trezvo.keystore TREZVO_KS_PASS=... TREZVO_KEY_ALIAS=trezvo
./gradlew assembleRelease
```

Либо положить ключ в `keystore/trezvo.keystore` (папка в .gitignore). Релиз с подписью собирается workflow `release.yml` по тегу `v*`.
