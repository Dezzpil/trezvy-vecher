# Трезвый вечер

Android-приложение для изменения привычки вечернего употребления. Пассивная часть: отметки тяги (сила, чего хочу, триггеры), чекпоинты дня, голосовые заметки, серии, советы, таймер волны тяги, выгрузка ZIP. Проактивная часть (1.1): приложение само предлагает, как провести вечер иначе — по готовым сценариям, без ИИ и без сети.

Не лечение и не инструмент самостоятельной отмены алкоголя. 18+.

Данные хранятся только на телефоне (`files/data.json` во внутреннем хранилище). Выгрузка: `journal.md`, `data.json`, `scenarios.json`, `audio/`.

## Устройство

| Путь | Что это |
|---|---|
| `app/src/main/assets/index.html` | Интерфейс (WebView): дневник, чекпоинты, тяга, настройки |
| `app/src/main/assets/engine.js` | Движок без UI: модель данных, миграция, подбор `rules-v1`, валидатор пакета. Работает в WebView и Node |
| `app/src/main/assets/ui-scenarios.js` | Экраны сценариев: анкета, «План вечера», карточки, обратная связь, «Мои сценарии» |
| `app/src/main/assets/content/core-ru.json` | Пакет контента: таксономия, 43 сценария, 4 сценария разговора. **Генерируется** из `tools/build-pack.mjs` |
| `app/src/main/java/.../Proactive.java` | Одноразовые напоминания, дневной лимит, тихие часы, восстановление после перезагрузки |
| `tools/` | Генератор и валидатор пакета, тесты движка |

### Как добавить или изменить сценарий

1. Править `tools/build-pack.mjs` (до появления бэк-офиса это и есть редактор). При изменении текста или условий — увеличить `revision` сценария; `id` не менять.
2. `node tools/build-pack.mjs && node tools/validate-pack.cjs && node --test tools/`
3. Валидатор проверяет таксономию, переходы и достижимость узлов, fallback у уличных сценариев, запреты (улица и нагрузка после употребления, формулировки в ветке «всё равно выпью»), и что каждому узлу предложений хватает минимум двух вариантов.

### Данные (schema_version 2)

Все новые записи: UUID, `created_at`, `updated_at`, `deleted_at`, `sync_state`, `local_date`, `tz_offset_min` — для будущей синхронизации с сервером. Коллекции: `profile`, `proactive`, `sessions`, `offers` (с `scenario_revision`, `ranker_id`, `score`, `features` — датасет для будущего ML), `responses`, `feedback` (null = «не ответил»), `prompts`, `prefs`, `events` (append-only журнал). Старые записи дневника мигрируют без смены id.

## Сборка

`./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`. CI: проверка пакета и тесты движка → сборка → самотест на эмуляторе Android 14.

## Подпись

Ключ подписи в репозиторий не входит. Без ключа release-сборка подписывается debug-ключом — такой APK **не встанет поверх** версии, подписанной твоим ключом.

```bash
export TREZVO_KEYSTORE=/path/to/trezvo.keystore TREZVO_KS_PASS=... TREZVO_KEY_ALIAS=trezvo
./gradlew assembleRelease
```

Либо положить ключ в `keystore/trezvo.keystore` (папка в .gitignore). Релиз с подписью собирается workflow `release.yml` по тегу `v*`.
